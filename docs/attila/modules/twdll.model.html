DisbandUnits (units)
Disbands (permanently removes) one or more units from the game. This mirrors the game's own UNIT::disband_units path, so each unit is fully removed from the world and all bookkeeping (events, dirty flags, force teardown) runs correctly. Unlike a bare container remove, this is save/load safe.

Parameters:

  • units vararg userdata, one or more UNIT userdata values to disband
