Module MERCENARY_POOLS

Mercenary pool methods on the game's region and faction objects (Attila).

Every province has a mercenary pool and every non-rebel faction has a faction-unique pool. These methods are available on REGION_SCRIPT_INTERFACE objects (the pool of the region's province) and on FACTION_SCRIPT_INTERFACE objects (the faction-unique pool):

region:GetMercenaryPool()                faction:GetMercenaryPool()
region:AddMercenaryUnits(key, n[, opts]) faction:AddMercenaryUnits(key, n[, opts])
region:RemoveMercenaryUnits(key, n)      faction:RemoveMercenaryUnits(key, n)
region:SetMercenaryUnitCap(key, cap)     faction:SetMercenaryUnitCap(key, cap)
region:SetMercenaryUnitReplenishment(key, chance, max_per_turn)  (and on faction)

Pools are part of the campaign model and are saved with the game, so changes persist. At the start of each turn the engine sets every unit's current cap to base cap x cap modifier (effects mercenary_province_pool_cap_mod / mercenary_faction_pool_cap_mod), clamps the available count to it and replenishes.

Multiplayer: call these from campaign model events that fire on every machine (e.g. FactionTurnStart, RegionTurnStart), never from UI events such as clicks, which only fire for one player and would desync the campaign.

Functions

AddMercenaryUnits (unit_key, count[, options])
Adds units to the mercenary pool. If the unit is not in the pool yet it is added as a new entry (persisted in saves); options then sets its cap and replenishment. Existing entries are only raised up to their current cap; raise the cap first with SetMercenaryUnitCap.

Parameters:

  • unit_key string main_units key
  • count integer units to add (>= 0)
  • options table for a new entry: { cap = integer (default count), replenish_chance = number (default 0), max_replenish = integer (default 0) } (optional)

Returns:

    integer or nil units now available, or nil on failure

Usage:

    -- In a FactionTurnStart listener (runs on every machine in multiplayer):
region:AddMercenaryUnits("att_merc_ger_agathyrsi_warriors", 2, { cap = 4, replenish_chance = 0.25, max_replenish = 1 })
GetMercenaryPool ()
Returns the units in the mercenary pool: for a region, its province's pool; for a faction, its faction-unique pool.

Returns:

    table or nil array of { unit, count, cap, base_cap, replenish_chance, max_replenish, experience } (cap is the current cap after modifiers), or nil if the pool could not be read

Usage:

    for _, u in ipairs(region:GetMercenaryPool() or {}) do
    out(u.unit .. " " .. u.count .. "/" .. u.cap)
end
RemoveMercenaryUnits (unit_key, count)
Removes units from the mercenary pool (the count never goes below 0). The entry stays in the pool; set its cap to 0 to stop it replenishing.

Parameters:

  • unit_key string main_units key
  • count integer units to remove (>= 0)

Returns:

    integer or nil units now available, or nil if the unit is not in the pool

Usage:

    faction:RemoveMercenaryUnits("att_merc_ger_agathyrsi_warriors", 1)
SetMercenaryUnitCap (unit_key, cap)
Sets a pool unit's base cap. The current cap keeps the existing modifier ratio until the engine recomputes it at the next turn start (base cap x cap modifier effects); the available count is clamped to it.

Parameters:

  • unit_key string main_units key
  • cap integer new base cap (>= 0; 0 effectively removes the unit)

Returns:

    integer or nil the current cap after the change, or nil if the unit is not in the pool

Usage:

    region:SetMercenaryUnitCap("att_merc_ger_agathyrsi_warriors", 6)
SetMercenaryUnitReplenishment (unit_key, chance, max_per_turn)
Sets how a pool unit replenishes at turn start: with probability chance (times the pool's replenishment modifier) it gains 1..max_per_turn units, up to its cap.

Parameters:

  • unit_key string main_units key
  • chance number chance per turn (0..1)
  • max_per_turn integer maximum units gained per turn (0 = never replenishes)

Returns:

    boolean true if changed, false if the unit is not in the pool

Usage:

    faction:SetMercenaryUnitReplenishment("att_merc_ger_agathyrsi_warriors", 0.5, 1)
