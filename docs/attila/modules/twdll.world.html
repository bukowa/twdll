Module twdll.world

SetMaxTraits (val)
Sets the maximum number of traits a character can hold simultaneously. Prevents new traits from being discarded when a character exceeds 10 traits.

Parameters:

  • val integer new maximum trait count (e.g. 20, 30, 50)

Usage:

    -- Expand character trait limit to 30:
twdll.world.SetMaxTraits(30)
SetMaxUnitsInArmy (val)
Sets the maximum number of units allowed per land army. Affects recruitment limits, army stacking, and UI capacity.

Parameters:

  • val integer new maximum unit count (e.g. 40)

Usage:

    -- Allow up to 40 units per land army:
twdll.world.SetMaxUnitsInArmy(40)
SetMaxUnitsInNavy (val)
Sets the maximum number of units allowed per naval fleet. Affects naval recruitment limits and fleet stacking.

Parameters:

  • val integer new maximum unit count (e.g. 30)

Usage:

    -- Allow up to 30 ships per naval fleet:
twdll.world.SetMaxUnitsInNavy(30)
SetReinforcementCap (max_units)
Sets the reinforcement cap (maximum concurrent units per army in tactical battles) for battles started after this call. Pass -1 to restore the vanilla engine default. Any value >= 0 is applied as an absolute cap.

Parameters:

  • max_units integer new cap value (e.g. 40, 80), or -1 to restore the default

Usage:

    -- Allow up to 40 reinforcement units simultaneously in tactical battle:
twdll.world.SetReinforcementCap(40)

-- Restore vanilla behavior:
twdll.world.SetReinforcementCap(-1)
