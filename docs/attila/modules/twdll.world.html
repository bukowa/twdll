AllowCustomCampaignKeys ([enabled=true])
Makes the game treat campaigns with custom keys as base-game content instead of unowned DLC. Without it, a mod campaign whose key is not main_attila/main_attila_map (or a DLC key) is shown as locked DLC, missing from multiplayer map lists and refused when joining a multiplayer campaign. Vanilla and DLC campaigns are unaffected.

Call it from the frontend (main menu) script so it is in place before campaign selection and the multiplayer lobby; every multiplayer player needs it. It stays in effect until disabled or the game exits (it is not rolled back on Lua teardown).

Parameters:

  • enabled boolean true to allow custom keys, false to restore the vanilla check (default true)

Returns:

    boolean or nil true if custom keys are now allowed, false if not, nil if the check was not found in this game build

Usage:

    -- In the frontend script:
twdll.world.AllowCustomCampaignKeys()
AllowGiftRegion ([enabled=true[, options]])
Offers the vanilla "Gift Region" diplomacy option between any factions, not only to hordes. By default it opens the option for the faction proposing the deal (the in-game tested case). Options add the reverse direction (the other side may give regions) and let hordes be givers; these two are not tested in game yet. A faction capital still cannot be gifted. Every multiplayer player must apply the same settings. Rolled back when the campaign's Lua state is torn down; call it again on every campaign load.

Parameters:

  • enabled boolean true to allow, false to restore the vanilla checks (default true)
  • options table { reverse = bool, horde_givers = bool } (optional)

Returns:

    boolean or nil true if applied, false if it could not be applied, nil if the code was not found in this game build

Usage:

    -- In the campaign script:
twdll.world.AllowGiftRegion()
-- Also let the other side offer regions, and hordes give them:
twdll.world.AllowGiftRegion(true, { reverse = true, horde_givers = true })
-- Back to vanilla:
twdll.world.AllowGiftRegion(false)

ProtectGovernorsOnRegionTrade ([enabled=true])
Keeps province governors alive when the region they live in changes hands through an accepted diplomacy deal: the vanilla Gift Region option, and regions offered or demanded in any other deal. The engine normally kills the general of the settlement's garrison (the governor living there) on every change of owner. While this is on, it records him as convalescing (wounded) instead, like an immortal character, and his own immortality setting is left exactly as it was (a mortal governor stays mortal). Captures, sacks, occupation decisions and cm:transfer_region_to_faction are not affected. Deals run on every machine, so in multiplayer every player must have it on. Removed when the campaign's Lua state is torn down; call it again on every campaign load.

Parameters:

  • enabled boolean true to protect governors, false for vanilla behaviour (default true)

Returns:

    boolean or nil true if protection is now on, false if it is off, nil if the code was not found in this game build

Usage:

    -- In the campaign script:
twdll.world.ProtectGovernorsOnRegionTrade()
-- Back to vanilla:
twdll.world.ProtectGovernorsOnRegionTrade(false)

SetCustomBattleDefaultMap ([mapname])
Sets which campaign map the custom battle screen selects when it opens. The game pre-selects the campaign_map_playable_areas row whose mapname is "main_attila_map"; this changes that name. Call it from the frontend (main menu) script. If no custom-battle row has the given mapname, the game falls back to its normal behaviour. A custom mapname (not main/bel/cha) also needs AllowCustomCampaignKeys(), otherwise the map is shown as locked DLC. Restored on Lua teardown.

Parameters:

  • mapname string mapname of a campaign_map_playable_areas row (max 63 characters), or nil to restore "main_attila_map" (optional)

Returns:

    string or nil the mapname now selected by default, or nil if the code was not found in this game build

Usage:

    twdll.world.SetCustomBattleDefaultMap("rom_third_age_map")
